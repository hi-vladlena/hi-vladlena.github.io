# Сайт-резюме Владлены

Простой статический сайт (HTML/CSS/JS), готов к публикации на GitHub Pages — сборка не нужна.

## Структура файлов

```
├── index.html          — вся разметка сайта (обе языковые версии в одном файле)
├── css/
│   └── style.css       — все стили, включая адаптив под мобильные
├── js/
│   └── script.js       — переключение eng/ru, модальные окна
├── images/              — все .webp картинки (превью, полноразмерные картинки проектов, фото, сертификаты)
└── cv/
    ├── Vladlena-CV-eng.pdf
    └── Vladlena-CV-ru.pdf
```

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `vladlena-cv`).
2. Загрузите в него **все файлы и папки из этого архива, сохранив структуру** —
   то есть `index.html`, папку `css`, папку `js`, папку `images` и папку `cv` нужно положить
   в корень репозитория (не во вложенную подпапку).
   - Проще всего: скачайте архив, распакуйте, перетащите всё содержимое в репозиторий
     через веб-интерфейс GitHub (Add file → Upload files), либо через git:
     ```
     git clone https://github.com/ВАШ_ЛОГИН/vladlena-cv.git
     cd vladlena-cv
     # скопируйте сюда содержимое папки site (index.html, css/, js/, images/, cv/, README.md)
     git add .
     git commit -m "Первая версия сайта-резюме"
     git push
     ```
3. Зайдите в репозиторий на GitHub → **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** (или **master**), папка **/ (root)**
5. Сохраните. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://ВАШ_ЛОГИН.github.io/vladlena-cv/`

Больше ничего настраивать не нужно — сайт полностью статический, без зависимостей и сборки.

## Что можно поменять при необходимости

- **Тексты** — прямо в `index.html`: у каждого переключаемого элемента есть два атрибута,
  `data-en="…"` (английский текст) и `data-ru="…"` (русский текст), плюс сам текст внутри тега
  (это то, что видно по умолчанию при загрузке — английская версия).
- **Картинки проектов/сертификатов** — просто замените файлы в `images/`, названия файлов
  не менять (или поменять заодно пути в `js/script.js`, в объектах `PROJECTS` и `CERTIFICATES`).
- **PDF резюме** — замените файлы в `cv/`, оставив те же имена
  (`Vladlena-CV-eng.pdf`, `Vladlena-CV-ru.pdf`), либо поменяйте пути в `js/script.js`
  в объекте `cvHref`.
- **Шрифт** — используется Impact везде (`font-family` в начале `css/style.css`).
  Impact — стандартный системный шрифт в большинстве Windows/macOS браузеров;
  если у пользователя его нет, браузер подставит ближайший похожий шрифт из списка fallback.

## Как всё это работает

- **Переключатель ENG/RU** (кнопка вверху) переключает `currentLang` в `script.js`
  и обновляет текст всех элементов с `data-en`/`data-ru`, фото (Me-eng/Me-ru),
  ссылку на PDF резюме и, если открыто модальное окно с картинкой — саму картинку.
- **Модальное окно «Сертификаты»** — открывает `Sertif_eng.webp` / `Sertif_ru.webp`,
  подгоняется по размеру самой картинки, скролла нет.
- **Модальные окна проектов**:
  - **Zastava** — открывается `Zastava_eng.webp` / `Zastava_rus.webp`, картинка широкая,
    целиком помещается в окно, скролла нет.
  - **Baush** и **Editorial Content System (Maslenitsa)** — открывают высокие картинки
    (`Baush_eng/ru.webp`, `Maslenitsa_eng/ru.webp`), окно фиксированной высоты,
    содержимое скроллится по вертикали.
- **Мобильная версия** (ширина экрана ≤ 900px) — все блоки остаются те же самые,
  просто идут вертикально друг под другом (грид перестраивается через CSS,
  без дублирования контента в HTML): имя → переключатель языка → заголовок специальности →
  подзаголовок → «Обо мне» + буллиты → контактный блок (orange, слева) →
  блок навыков (orange, справа) → остальные секции. Фото на мобильной версии скрыто.
  Нумерация секций (01–05) с вертикальной линией сохранена и на мобильной, и на десктопной версии.
